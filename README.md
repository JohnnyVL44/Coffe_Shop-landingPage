# ☕ Landing Page – Cafetería

Landing page moderna y responsiva diseñada para una cafetería, con el objetivo de transmitir su identidad, presentar sus productos y ofrecer a los visitantes una experiencia visual agradable e intuitiva.

El proyecto combina un diseño atractivo, una navegación sencilla y una estructura adaptable a diferentes dispositivos, buscando reflejar la esencia y personalidad de una cafetería a través de su presencia digital.

## Características principales

- **Diseño moderno:** Interfaz visualmente atractiva, con una estética cálida y acorde con la identidad de una cafetería.
- **Diseño responsivo:** Adaptación a diferentes tamaños de pantalla, incluyendo dispositivos móviles, tablets y computadoras.
- **Navegación intuitiva:** Estructura sencilla que facilita el acceso a las diferentes secciones de la página.
- **Estilos personalizados:** Diseño desarrollado utilizando Tailwind CSS.

## Tecnologías utilizadas

| Tecnología | Descripción |
|---|---|
| HTML5 | Estructura y organización del contenido. |
| Tailwind CSS | Diseño, estilos y adaptación responsiva. |
| JavaScript | Interactividad y funcionalidades dinámicas. |

## Instalación y ejecución

No se requiere ninguna instalación especial para visualizar el proyecto.

1. Clona este repositorio:

   ```bash
   git clone URL_DEL_REPOSITORIO
   ```

2. Accede a la carpeta del proyecto:

   ```bash
   cd landing-page-cafeteria
   ```

3. Abre el archivo `index.html` en tu navegador o utiliza la extensión **Live Server** de Visual Studio Code para ejecutarlo en un servidor local.

## Objetivo del proyecto

Este proyecto forma parte de mi desarrollo profesional como programador para practicar y aprender más sobre **TailwindCSS**, poniendo en práctica conocimientos de desarrollo frontend, diseño responsivo y experiencia de usuario (UX).

Más allá de presentar información, una buena landing page debe transmitir la personalidad de una marca, captar la atención de sus visitantes y convertir una primera impresión en una experiencia memorable.
